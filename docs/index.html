Lumber Inventory Manager

An offline-first lumber inventory database with a full transaction ledger. Receive boards, search in plain English, reserve and allocate stock to projects, consume boards on the saw, and watch every offcut automatically roll back into inventory. SQLite-backed — negative inventory is impossible by construction.

TypeScriptNode.js ≥ 22.5MIT License15 tests

Part of the open-source BoardFootCalc desktop tool suite — the same board-foot math as the online lumber calculators, offline and scriptable on your own machine.

Features

  • SQLite storage via Node’s built-in node:sqlite — zero native compilation, one .db file per yard.
  • Transaction ledger — every add / edit / move / reserve / allocate / release / consume / scrap / sell writes a ledger entry with the previous and next item snapshot.
  • Natural-language search — "find boards at least 8/4 x 10 x 72 walnut" parses to thickness ≥ 2", width ≥ 10", length ≥ 72", species walnut.
  • Projects & allocation — reserve → allocate → release, with Required BF / Available Matching BF / Shortfall / Potential Waste computed before you commit anything.
  • Consumption & offcuts — consume a length from a board; the remainder re-enters stock as a new offcut item linked to its parent.
  • Status model — AVAILABLE → RESERVED → ALLOCATED → CUT, plus SCRAP / SOLD, guarded transitions only.

Quick start

npm run demo
bfc-inventory search "at least 8/4 x 10 x 60 walnut"

Full CLI reference, input formats and design notes are in the repository README.
